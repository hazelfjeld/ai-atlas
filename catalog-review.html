Terminology adjudication

Distinct useful term candidate · not imported

Agent harness

The surrounding execution system supplying tools, observations, permissions, state, retries and stopping rules. This is narrower and more implementation-specific than an agentic workflow; the same model weights may perform differently in two harnesses.

Before giving it its own stable ID, relate it explicitly to agentic workflows, tool use and orchestrators. Do not attribute tool behavior to the model alone.

Distinct useful term candidate · not imported

Semantic ontology layer

A governed layer of entities, metric definitions, relationships, access rules and lineage used to interpret data for analytics or agents. It overlaps with a knowledge graph but has an additional semantic governance and query-grounding role.

It does not guarantee underlying data accuracy or grant authorization to all connected systems. Keep the boundary with ordinary semantic search explicit.

Compound phrase · no separate ID proposed yet

Environment-grounded agent benchmark

Describes a benchmark plus an interactive environment, where the final task state matters more than fluent prose. Those components already have stable, expanded pages. Treat this as a useful retrieval phrase, not automatically a distinct foundational term.

A future separate record needs evidence of established usage and a mechanism beyond combining existing definitions. Sandbox quality, contamination and graders remain limitations.
