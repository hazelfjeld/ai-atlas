Language-model training and adaptation · MLD-0431

Fine-tuning

Continuing training from an existing checkpoint for a task, domain, or behavior.

Expanded guide · editorial review 2026-11-01. Original definitions, examples, notes and citations are preserved below. New examples are illustrative, not benchmark results.

Prerequisites

  • Large language model
  • Overfitting

How it works

Fine-tuning continues training from existing parameters for a new task or distribution. Full fine-tuning updates many or all weights; parameter-efficient methods train a smaller set. LoRA, for example, learns low-rank weight updates while freezing the base weights. Prompting changes input context and ordinarily leaves weights unchanged.

Worked example

For an illustrative report-formatting task, collect approved input-output pairs and hold out whole document families. Compare the base model with a prompt-only approach and an adapted model. Evaluate whether formatting improves without increasing invented facts or degrading unrelated tasks.

A useful parameterization

LoRA represents an update as Delta_W = B A, where the intermediate rank is small relative to the original matrix dimensions. This reduces trainable parameters; it does not remove every other training-memory cost.

What to test

Check unseen documents, long inputs, malformed requests and general-language regressions. Record the base model, tokenizer, adapter, dataset split and training settings so the result can be reproduced.

Common pitfall

Fine-tuning on examples is not a dependable way to keep changing facts current. Separate behavior adaptation from document retrieval and factual verification.
