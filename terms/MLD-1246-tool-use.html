Agents and tool use · MLD-1246

Tool use

A model-driven system requesting external functions or services and consuming their results.

Original reference page · detailed expansion pending. Original definitions, examples, notes and citations are preserved below. New examples are illustrative, not benchmark results.

Original example

Call a calculator or document search tool.

Original caveat

The surrounding application executes tools; text alone does not.
