Causal intervention

A controlled change used to test how a system's outputs depend on a component or variable.

Expanded guide · editorial review 2026-11-03. Original definitions, examples, notes and citations are preserved below. New examples are illustrative, not benchmark results.

Prerequisites

  • Causal inference
  • Counterfactual
  • Mechanistic interpretability
  • Agent evaluation

An intervention is a controlled change, not a correlation

A causal intervention changes a specific variable or mechanism while comparing a defined outcome with an otherwise matched condition. In a causal graph, setting X to a chosen value is written do(X=x), which differs from merely observing X=x. In a neural network, replacing a hidden activation is an intervention on computation, not necessarily on a real-world cause.

Define the target and counterfactual baseline

Begin with an outcome Y, an intervention target X and two conditions such as do(X=x1) versus do(X=x0). A causal effect is the difference E[Y | do(X=x1)] minus E[Y | do(X=x0)] under a specified experimental population. It is not equivalent to the conditional difference E[Y | X=x1] minus E[Y | X=x0] when common causes or selection effects are present.

Interchange interventions inside a network

In causal-abstraction research, run a model on a base input and on a separate source input, then replace selected internal values in the base run with their source-run values. Compare the resulting output to an explicitly proposed high-level causal model under an analogous intervention. Agreement tests an alignment hypothesis; a matching probe prediction without interventions does not establish that hypothesis.

A toy activation-patching experiment

Imagine a two-input toy classifier where the baseline predicts class A with probability 0.25 and the clean source state predicts A with probability 0.90. Patching one registered layer and token into the baseline yields 0.70. The illustrative recovery is (0.70-0.25)/(0.90-0.25) = 0.6923, or about 69%. This is a normalized change in this toy setup, not a universal attribution score or proof of a unique causal path.

Specify exactly where and when to intervene

Choose model version, prompt/input pair, token index, layer, head or feature, intervention magnitude, sampled counterfactuals and outcome metric before looking at results. Restoring a whole residual stream may affect many downstream computations at once; ablating a feature to zero can also produce out-of-distribution activations. A carefully localized effect is still conditional on the intervention family.

Examples beyond activation patching

Interventions can randomize a treatment in a controlled trial, remove one tool permission in an agent sandbox, replace a retrieval document, or alter a model's hidden state. These change different causal objects: real-world exposures, system interfaces, input context or internal representations. A tool-permission ablation tests the complete agent system, not only the language model weights.

Positive and negative controls

Use no-op patches, patches at unrelated sites, source/base swaps, randomized intervention assignments and independent holdout inputs. Match seeds, prompting, model state and token alignment where relevant. Report both directions of the effect and any failed cases; selecting the best layer after scanning hundreds of sites without held-out confirmation exaggerates apparent specificity.

When the causal interpretation fails

A successful patch may restore output while bypassing a distributed or redundant circuit, so it need not locate the single information store. Confounded observational datasets, non-overlapping treatment groups, activation distribution shift and evaluator leakage can also invalidate a causal story. Geiger and colleagues formalize abstractions conditionally on proposed alignments and intervention families, not as automatic discoveries.

Research use and reporting checklist

For a reproducible study, preregister the causal contrast and candidate mechanisms, freeze model/data hashes, retain base/source pairing rules, test alternative paths and provide uncertainty over examples rather than only tokens. Distinguish intervention effects on a model from claims about external-world incidents or enduring model goals. Report precisely which counterfactual comparisons the evidence supports.
