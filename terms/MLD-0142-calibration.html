Evaluation metrics and uncertainty · MLD-0142

Calibration

Agreement between predicted probabilities and observed frequencies under a defined evaluation.

Expanded guide · editorial review 2026-11-02. Original definitions, examples, notes and citations are preserved below. New examples are illustrative, not benchmark results.

Prerequisites

  • Machine learning
  • Brier score
  • Expected calibration error
  • Distribution shift

What calibrated confidence means

A probabilistic classifier is calibrated when, among predictions assigned confidence near p, the selected class is correct about a fraction p of the time. Formally, P(correct | confidence = p) = p is the idealized top-label property; in finite data we examine confidence bins. Calibration describes agreement of probabilities with observed frequencies, not accuracy, discriminative ability, causal understanding or trustworthy behavior.

Interpret an illustrative reliability gap

Suppose a completely synthetic model emits 100 class predictions with confidence 0.80 and only 60 are correct. The empirical accuracy in that group is 60/100 = 0.60, so the observed overconfidence gap is 0.20, or 20 percentage points. This is an invented teaching example, not a measured result. A small bin has sampling uncertainty; report the numerator, denominator and confidence interval instead of asserting the true error equals the observed gap.

Use proper scores and diagnostics together

For binary outcomes y in {0,1} and predicted event probabilities p, the Brier score is mean((p-y)^2), while negative log-likelihood is mean(-y log p - (1-y) log(1-p)). Lower is better for both. Compare these proper scores with reliability diagrams, predictive accuracy, selective-risk curves and classwise performance; a model can have high accuracy but poor calibration, or trivial calibration with little discrimination.

Audit expected calibration error carefully

A common top-label expected calibration error (ECE) estimate is sum over bins B of (|B|/n) * |accuracy(B)-mean_confidence(B)|. Freeze bin edges and the population definition before inspection. Compute each bin's count, mean confidence and observed correctness. ECE is sensitive to binning, sample size, confidence range and whether all class probabilities are assessed. A low estimated ECE does not prove that rare subgroups are calibrated.

Temperature scaling is post-hoc calibration

Given frozen classification logits z and positive scalar T, fit T on a separate calibration split by minimizing negative log-likelihood, then output softmax(z/T). With T greater than 1, scores generally soften; the ordering of logits is unchanged and top-1 accuracy therefore usually stays fixed for a positive common T. This is logit temperature scaling, NOT the sampling temperature that changes randomness in LLM text generation. Refit only when allowed by a predeclared protocol.

Check shift, class balance and subgroups

Inspect per-label and per-subgroup reliability, especially for rare or consequential outcomes. Distribution shift can change the mapping between confidence and empirical accuracy even when the original validation set looked calibrated. Rechecking a held-out target-domain slice and stating missing labels is more informative than assuming a single global scaling factor transfers to every domain or group.

Run a bounded reproducible calibration experiment

Proposed synthetic audit, not an executed benchmark: generate or select labeled examples with a frozen seed, separate model-training, calibration and final test partitions by entity and time, freeze all model choices, and fit one scalar T on calibration data only. On untouched test data report accuracy, Brier score, negative log-likelihood, bin counts and ECE with several predeclared bin schemes, both before and after scaling. Repeat across seeds and report variation; never tune T using the final test labels.

Use probabilities without confusing them with permission

Calibration may help triage uncertain predictions, build abstention thresholds and prioritize human review, but a well-calibrated score does not establish that a tool-using agent obeyed instructions. For a safety decision, separately audit forbidden tool actions, final environment state, group harms and consequences of false reassurance. If confidence is verbalized by a language model rather than derived from a specified probability interface, validate that interface independently.

Limitations, misconceptions and evidence boundary

Measured calibration depends on which event, population, time window and prediction interface are defined. No finite test establishes perfect calibration everywhere; post-hoc correction can conceal underlying model weaknesses and fail after deployment shifts. The cited work studies measured classifier behavior and calibration estimators; this guide presents mechanisms and a proposed synthetic audit, not a newly reported AI incident or a guarantee of safe operation.
