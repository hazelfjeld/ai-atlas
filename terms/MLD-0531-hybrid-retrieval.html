Hybrid retrieval

Combining different retrieval approaches, often lexical and dense semantic search.

Technology connections

  • Chroma — Embedding-oriented retrieval database and application tooling.
  • Elasticsearch — Distributed search and analytics engine.
  • FAISS — Library for dense-vector similarity search and clustering.
  • hnswlib — Library implementing HNSW approximate nearest-neighbor indexes.
  • LanceDB — Vector database built around the Lance columnar format.
  • Milvus — Distributed vector database.
  • OpenSearch — Open-source distributed search and analytics suite.
  • pgvector — PostgreSQL extension for vector similarity search.
  • Pinecone — Managed vector-database service.
  • Qdrant — Vector database with payload filtering and retrieval APIs.
  • Vespa — Search and recommendation serving engine with programmable ranking.
  • Weaviate — Object and vector database with hybrid retrieval features.
