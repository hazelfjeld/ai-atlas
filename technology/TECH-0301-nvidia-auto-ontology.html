TECHNOLOGY PROFILE · TECH-0301

NVIDIA Auto Ontology

Framework for semantic catalogs and ontology-backed natural-language queries over structured enterprise data.

First-party code, README and licensing reviewed 2026-11-03; operation and model-quality claims not independently reproduced. Added after the original November 1 snapshot; not a new product launch or independent benchmark replication.

Where it has an edge

Shared metadata, definitions and provenance can ground agent analytics across connected data sources; product capability, not an independently measured accuracy advantage.

Best-fit problems

Evaluating governed, natural-language analytics over relational business data with cross-system definitions and lineage.

Tradeoffs & cautions

Check generated SQL and database permissions. FastAPI trusts an identity header from an authenticated Next.js gateway and must remain an internal service. Without Vault, UI-added database credentials can be stored unencrypted in Postgres.

What to test before choosing

Connect an isolated read-only test database; test query correctness against held-out known answers, RBAC, prompt injection controls, gateway isolation, credential storage and NIM usage cost.

Runtime & hardware

Docker Compose v2 or Kubernetes, Next.js, FastAPI Python 3.12+, PostgreSQL/pgvector, configured NVIDIA NIM endpoints and database credentials.

Access & licensing

NVIDIA-authored code is Apache-2.0; separate third-party notices and model, source-database and hosted inference licensing or fees apply.

Execution

Local / self-hosted

Lifecycle

Source repository publicly documented; initial public release date unverified

Comparison basis

First-party documentation review, not head-to-head comparison or validated SQL correctness.

Original notes

New to Atlas on November 3, not a November 3 product launch. Initial public release date unverified. Backend identity-header trust and plaintext credential fallback require special deployment care.

Connected concepts

  • Retrieval-augmented generation

Alternatives to investigate

LlamaIndex with governed data connectors · LangChain with authorized database tools · Established enterprise semantic BI layers
