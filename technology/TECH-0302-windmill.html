TECHNOLOGY PROFILE · TECH-0302

Windmill

Code-first platform for scripts, scheduled jobs, APIs, workflows and internal apps, with optional agent and MCP integrations.

First-party v1.856.0 release notes, tagged README and LICENSE reviewed 2026-11-03; feature operation, authentication security and performance not independently reproduced. Added after the original November 1 snapshot; not a new product launch or independent benchmark replication.

Where it has an edge

Turns maintained scripts into workflows and human-facing apps with Git-based review and worker isolation; an available design capability, not an independently measured speed or security advantage.

Best-fit problems

Teams combining Python, TypeScript and SQL automations with internal forms, approval processes, integrations and auditable deployment review.

Tradeoffs & cautions

A documented external-OIDC-token feature is not a security certification. Check issuer, token audience, role/workspace mapping, least privilege, secret access and worker isolation; review AI-generated code before deployment.

What to test before choosing

Deploy isolated test workers and a read-only demo integration. Check Git review gates, scoped OIDC access to MCP tools, user/workspace RBAC, secret handling, failure retries and job isolation; measure real workload latency and operational cost.

Runtime & hardware

Self-hosting documented with Docker Compose or Kubernetes, PostgreSQL, server and separate workers; resource needs depend on job language, concurrency and workloads. Managed hosting, auth providers and optional secret backends have separate setup and costs.

Access & licensing

At v1.856.0, backend/frontend source is principally AGPLv3 with documented exceptions; clients and OpenAPI specs are Apache-2.0. Distributed Community Edition binaries include proprietary features and use/distribution limits; enterprise and commercial embedding/managed-service rights differ. Check the exact LICENSE before redistribution.

Execution

Self-hosted or managed service

Lifecycle

Existing software, source-reviewed at tagged v1.856.0; initial public release date not independently established

Comparison basis

Conceptual first-party feature comparison; no measured throughput, reliability or authorization-security benchmarks reproduced by Atlas.

Original notes

New to Atlas on November 3, not a new product launch. The November 2 v1.856.0 notes report external OIDC issuer access tokens for MCP, not universal support across all configurations; later versions may exist.
